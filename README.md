# memindanao (the portfolio, the website, the start)

My personal website, where I might upload stuff like projects or other stuff about me.

## Tech stack
- React 19 + Vite 6
- Tailwind CSS v4
- Framer Motion 
- Vercel

## Edit content
Almost everything lives in **`src/data.js`** — About, projects, experience, education, skills, and contact links. Each project is one block with a title and bullet points. Content that's not known yet is left out rather than invented.

## Run it locally
```bash
cd personal-website
npm install
npm run dev
```
Then open the localhost link it prints.
